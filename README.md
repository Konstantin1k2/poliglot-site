# Полиглот — школа иностранных языков

Статический многостраничный сайт школы иностранных языков «Полиглот» (г. Хабаровск):
английский и китайский язык для детей и взрослых, подготовка к ОГЭ и ЕГЭ.

## Технологии

- Чистый HTML5, CSS3 и ванильный JavaScript (без сборщиков и зависимостей).
- Раздаётся как статика (например, GitHub Pages).

## Структура

```
index.html            — главная (лендинг): hero-слайдер, преимущества, отзывы, видео + карта, модальные окна
pages/
  about.html          — О школе
  programs.html       — Программы обучения
  reviews.html        — Отзывы
  contacts.html       — Контакты и карта
css/styles.css        — единый файл стилей (дизайн-токены, компоненты, адаптив)
js/
  contacts.js         — единый источник контактных данных, гидратация [data-contact-field]
  navigation.js       — мобильное меню, активный пункт, scroll-reveal, год в подвале
  modals.js           — модальные окна с управлением фокусом и прокруткой
  slider.js           — слайдер фотографий (уважает prefers-reduced-motion)
  map.js              — зум и карточка адреса на встроенной карте OpenStreetMap
assets/               — изображения и видео
```

## Заметки

- Контактные данные правятся централизованно в `js/contacts.js` — они автоматически
  подставляются во все элементы с атрибутом `data-contact-field`.
- Версии ассетов (`?v=YYYYMMDD`) синхронизированы между всеми страницами; при правке
  CSS/JS обновляйте дату одновременно во всех файлах.
- Для локального просмотра достаточно открыть `index.html` в браузере.
